# 更新说明

## v0.3.1

### 变更
- 扩展醒来、活动开始、活动结束与计划调整的公开事件表达，可用 social_event_types 缩小范围。
- 读取 Host 共享人设、公开生活事实、当前群关系摘要及最近已发送事件类型。
- 增加发送前版本重检、持久化结果与有界账本维护；不重试结果未知的发送。
- 修复 WebUI 配置 Schema；空路由草稿仍不能作为运行绑定。
- 文档改为可选扩展定位（opt-in），三核心安装不要求 Coordinate；保留默认 shadow，不改变运行逻辑。

### 兼容性
- 配置格式版本 "1"；支持 Host 1.3.12 / SDK 2.15.0、Host 1.3.15 / SDK 2.16.0。
- 对接 MaiVita 0.6.1、MaiIdentity 3.2.2、MaiHush 0.2.2 的公开接口。

## v0.3.0

### 变更
- 从 Host 实际接收消息发现路由，并与 Hush 已管理群的公开绑定核对，最多四群。
- 空 scope 精确匹配 None；新绑定不补发发现前的旧事件，保留显式路由模式。

## 早期协调层

### 变更
- 提供公开状态聚合、shadow 观察及显式 controlled 表达。
- 持久化事件游标、幂等记录和冷却，过期事件不补发，unknown 不自动重发。

历史来源保存在 MaiVita 仓库 ecosystem/coordinator；工作区副本没有独立 Git 历史。
