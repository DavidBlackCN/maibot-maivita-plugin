# 已知限制

- H01：宿主未透传可信管理回执绑定，睡眠发送无例外；不信任 kwargs、Owner 字段或提示词。
- H02：SDK 无插件归属化频率撤销契约。两种引擎的调频关闭，Manifest 不声明 frequency.set_adjust，不全局复位频率。
- H03：Owner Auth 只有已审计的提示注入，无可用可信身份声明接口。新引擎管理写入/唤醒/私密查询拒绝；统一策略与主动社交传输也关闭。
- 当前仅冻结接口形状与错误语义；没有实现对方并不存在的 API，没有声明生态联调已通过。
- life 引擎只读命令使用正常 send.text，睡眠时不发送、不唤醒。planner 仅适配已核实的 extra_prompt 形状，未知 typed item 安全跳过。
- legacy 引擎保留固定睡眠与旧命令权限；它没有新库生活状态，不能让消费者把旧计划当实际历史。
- life 模式未注册旧 update_schedule_v4 角色裁判变更 Tool，调用得到 Host 未注册错误；legacy 模式保留该组件但管理写入拒绝。旧消费者完整迁移仍需联合阶段清单验证，不能把未接线工具伪装成成功。
- 模型超时/未知结果不自动重试，可能已产生供应商费用。预算不保证供应商计费完全一致；不持有写事务等待模型。
- 不自动导入/升级/降级数据库。歧义迁移、未知 Schema、损坏库和无合法切换票据都拒绝激活，不删库重建。
- 原生过程树隔离测试目前要求 Windows；已验证的 CI 为 Windows/Python 3.13 组合。legacy 的自动日程生成和指定模型内部适配未作为本轮真实模型验收目标，验收配置明确关闭其自动生成与主动发送。
- 外部平台送达、多插件 Hook 链、Owner/策略/社交/记忆互通、性能与长期观察统一移交超级 MaiBot 核心插件联合测试。
- 完整 Host 的可选 embedding 未配置；沙箱禁止内置 plugin-management 写相邻源码目录。未修改宿主来掩盖这些限制。

Integration Ready 仅表示本项目规定的静态、单元、真实隔离 Runner/Host、有限真模型与故障恢复自动门禁通过，不代表生产批准或所有历史阶段正式通过。
