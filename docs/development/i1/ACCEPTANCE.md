- [ ] 确认 EULA/隐私同意、关闭遥测、实例为空且与生产隔离。

- [ ] 公开新 API/旧裸形状和完整 alias 指向同一状态；Tool 与命令可读，伪造 Owner/authorized/source 不会管理写入。

- [ ] 独立合成库备份恢复验证 checksum 和状态，不改旧库，不自动迁移，不恢复历史发送。
