# I1 Integration-Ready 自动门禁

当前版本为 0.3.1，机器验收状态见 [integration-ready.json](integration-ready.json)。2026-10-27 对当前源码重新完成 Linux / Python 3.12.15、Host 1.3.15（`062d45cf8bd4272ac57d7ec03fcf405e5a458211`）/ SDK 2.16.0 的完整 I1：完整 Host CLI/WebUI、一次真实模型合法候选提交、API/Tool/Command/Hook、权限拒绝、重载、单写者、legacy/life 回切与校验恢复。数据库确认专用模型实际成功调用一次，没有连接 QQ，也未读取生产聊天。

当前源码的 Windows 离线回归为 222 项通过、1 项 Linux 专用清理测试跳过、103 个子用例通过；Linux 为 223 项及 103 个子用例通过。原始 I0 Runner 与清理夹具继续固定 Host 1.3.12 / SDK 2.15.0，不能冒充新版 Host 验证。新版完整 Host 与三核心联合测试分别记录独立证据。历史 2026-10-26 的旧源码/旧 Host I1 保留在历史交付目录，没有用它替代本次模型记录。CI 仅代表所列工作流的检查；真实 QQ、长期稳定性与生产部署仍未验收。完整 Bot 快速清单约 30～45 分钟，不要求先等待七天。

本轮取消单插件独立 24 小时/7 天门禁；长期观察和真实生态联调统一交给超级 MaiBot 核心插件联合测试。这是验收范围变更，不把未运行的观察标成通过。

必需检查：静态编译/清单/配置与契约、完整单元回归、可公开源码独立导出验证、固定真实 Runner IPC 冒烟、完整 Host 注册/调用/重载、至少一次预算内真实模型合法候选提交、单写者及受控新旧切换/回切、加载失败清理、离线迁移与一致备份恢复、源码/凭据/包内容审计。任何缺项不得生成 Integration Ready 结论。

门禁必须绑定当前可执行文件指纹及固定 Host/SDK；文档单独核对并随包提供。CI 不持有模型密钥，只运行无凭据的静态、单元和原始 Runner 检查；有限真模型与完整 Host 在本地受控实例中验证，不能把 CI 绿色当成真模型验收。

联合测试待办：可信 H01/H02/H03 协议、真实平台送达与失败、Owner 通过但策略拒绝、社交事件重送去重/到期不发送、多 Hook 并存、24 小时/7 天整体观察、跨插件资源回收和生产迁移另行授权。门禁完成后冻结独立功能开发。
